# منصة الصوت · Audio Express

منصة صوت عربية تعمل في المتصفح من ملف HTML واحد: تحويل النص إلى صوت، والصوت إلى نص، ومحرر صوتي، واستوديو مكساج.

> برمجة: حسن الفيفي · Hassan Alfaifi — للدعم: aboanas990@yahoo.com

> هذا الملف يصف الإصدار الحالي `audio-platform13.html`. ملف README السابق كان يصف نسخة قديمة تعمل بخادم بايثون، ولم تعد مستخدمة.

## التشغيل
1. افتح `audio-platform13.html` في Chrome أو Edge (الأفضل للتسجيل والكتابة الفورية).
2. يحتاج اتصالًا بالإنترنت لتحميل المكتبات والنماذج عند أول استخدام (onnxruntime-web، transformers.js، Piper، lamejs، GSAP). النماذج تعمل بعد ذلك على جهازك.
3. لا خادم ولا تثبيت.

## الأقسام
- **نص ← صوت:** أصوات تعمل على الجهاز أو أصوات المتصفح، عربية وإنجليزية، رجل/امرأة، طابع الصوت، السرعة والطبقة والمستوى، والتنزيل بصيغة WAV أو MP3.
- **صوت ← نص:** تفريغ بنموذج Whisper على جهازك (سريع/متوازن/دقيق)، من المايك أو ملف صوتي، مع تصدير TXT وترجمة SRT.
- **محرر الصوت:** قص ونسخ ولصق، تقسيم تلقائي عند الصمت، وأكثر من 30 تأثيرًا (تسوية، LUFS، معادل 10 نطاقات، بوابة ضوضاء، تقليل الضوضاء، إزالة الغناء، Auto-Tune، صدى…)، مع أدوات تحليل (الجهارة، الترددات، BPM).
- **الاستوديو (مكساج):** دمج عدة مسارات.
- **مختبر الأصوات.**
- **استخراج الصوت من فيديو** بالحجم المختار.

## الترخيص
المنصة مربوطة بخادم التراخيص الموحد Express Licence (`express-license.ha-studio.workers.dev`).
- كل الأدوات تعمل دون تفعيل. **تنزيل الملفات وتصديرها** يحتاج تجربة مجانية (7 أيام) أو رخصة مفعّلة.
- التفعيل يتم مرة واحدة عبر الإنترنت، ثم يتحقق البرنامج كل 7 أيام، ويعمل دون اتصال حتى 30 يوماً.
- زر الترخيص في أسفل الصفحة يفتح نافذة الشراء والتفعيل وإلغاء التفعيل.
- عند التفعيل يُرسَل إلى الخادم مفتاح الترخيص ومعرّف عشوائي للجهاز واسمه، ولا يُرسَل أي ملف صوتي.
